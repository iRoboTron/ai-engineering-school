# ИИ для 9 класса

Курс из семи тем о том, как на самом деле устроен искусственный интеллект — для школьников,
которые уже немного программируют. Простым языком, со схемами, повторениями и маленькими
лабораторными на Python, которые запускаются без ключей, интернета и установки библиотек.

Сделан на основе взрослого курса `../ai-engineering` (интенсив для разработчиков): темы те же,
изложение и глубина — школьные.

В каждой теме есть словарик терминов со схемами.

## Как открыть локально

```bash
cd docs/books
python3 -m http.server 8099 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8099/index.html — это каталог тем. Читалка (`reader.html`) собирает
всю тему в одну страницу: можно читать подряд, переходить по оглавлению и печатать в PDF.

Всё работает офлайн: библиотеки (marked, highlight.js, mermaid, DOMPurify) лежат в `vendor/`,
внешних CDN нет.

## Лабораторные

```bash
python3 docs/books/labs/tema1-llm-osnovy/01_tokeny.py
```

Все восемь скриптов запускаются одной командой, используют только стандартную библиотеку и
ничего никуда не отправляют. Настоящую модель везде заменяет простая функция-заглушка — так
виден сам механизм, а не работа чужой библиотеки.

| Файл | Что показывает |
|---|---|
| `tema1-llm-osnovy/01_tokeny.py` | Как текст режется на токены и почему русский «дороже» |
| `tema1-llm-osnovy/02_temperatura.py` | Крошечная языковая модель и влияние температуры |
| `tema1-llm-osnovy/03_instrumenty.py` | Цикл «модель просит инструмент — программа выполняет» |
| `tema2-rag/01_mini_rag.py` | Мини-RAG: чанки, поиск по словам, сборка запроса |
| `tema3-vektory/01_poisk_po_smyslu.py` | Поиск по смыслу через косинусную близость |
| `tema4-agenty/01_agent.py` | Агент с двумя инструментами и четырьмя границами |
| `tema5-provierka/01_proverka.py` | Замер качества на эталонном наборе, до и после улучшения |
| `tema6-bezopasnost/01_podmena.py` | Как выглядит подмена инструкций и как от неё защищаются |

Код в уроке и код в файле — одно и то же: в уроке он вставлен, чтобы читать не отходя,
а файл нужен, чтобы запустить и поменять.

## Структура

```
docs/books/
├── index.html          каталог тем
├── reader.html         читалка
├── files.json          манифест: какие темы и уроки существуют
├── NN-slug/            тема: book.md, chapter-NN.md, glossary.md
├── labs/temaN-slug/    лабораторные .py
└── vendor/             офлайн-библиотеки
```

Правила написания уроков — в [AUTHORING-CONVENTIONS.md](AUTHORING-CONVENTIONS.md).

## Проверка перед публикацией

```bash
# все лабораторные запускаются
for f in docs/books/labs/*/*.py; do python3 "$f" >/dev/null || echo "СЛОМАНО: $f"; done
```

Плюс глазами в браузере: схемы рисуются, подсветка кода работает, ссылки на лабы открываются.
При изменении контента поменяй `ASSET_VERSION` в `index.html` и `reader.html` (и в теге
`reader-links.js?v=` — три места должны совпадать), иначе браузер отдаст старую версию из кэша.
